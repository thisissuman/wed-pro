# Mobile UX Skill

## Purpose

This skill defines how mobile user experience should behave across:
- dashboard
- editor
- onboarding
- public invitation pages

Mobile UX is the highest product priority.

---

# Core Philosophy

The product should feel:
- effortless
- touch-friendly
- smooth
- lightweight
- responsive

Most users will access the product through mobile devices.

---

# Touch Interaction Rules

All interactive elements must:
- remain easy to tap
- support thumb interaction
- maintain proper spacing

Minimum touch target:
- 44px × 44px

Avoid crowded layouts.

---

# Navigation Philosophy

Mobile navigation should feel:
- simple
- lightweight
- intuitive

Prefer:
- bottom actions
- collapsible menus
- clean navigation hierarchy

Avoid:
- enterprise dashboard complexity
- deep nested menus

---

# Typography Rules

Typography must remain:
- readable
- breathable
- scalable

Avoid:
- tiny text
- cramped line heights
- excessive font mixing

---

# Editor UX

The editor experience must feel:
- instant
- responsive
- easy to use

Prefer:
- live preview
- stacked mobile layouts
- simple controls

Avoid:
- complex editing interfaces
- overwhelming settings

---

# Scroll Experience

Scrolling should remain:
- smooth
- natural
- uninterrupted

Avoid:
- scroll-jacking
- heavy scroll animations
- nested scroll containers

---

# Mobile Performance

Optimize aggressively for:
- low-end Android devices
- slow mobile networks
- limited hardware

Avoid:
- excessive animations
- large bundles
- heavy rendering

---

# Dashboard UX

Dashboard flows should remain:
- guided
- lightweight
- easy to understand

Avoid:
- admin panel complexity
- overcrowded layouts
- excessive navigation layers

---

# Public Invitation UX

Invitation pages should:
- load quickly
- feel immersive
- remain readable
- support smooth sharing experience

Guest experience matters heavily.

---

# Final Principles

Always prioritize:
1. usability
2. touch experience
3. readability
4. performance
5. smooth interaction

Mobile UX should feel:
- premium
- calm
- lightweight
- effortless
