# Mobile First Rules

## Core Philosophy

This product is primarily mobile-focused.

All UI, UX, layouts, interactions, and flows must be designed for mobile devices first.

Desktop layouts should adapt from mobile layouts, not the reverse.

The majority of users will:
- discover the platform through Instagram or WhatsApp
- access invitations through mobile browsers
- edit invitations on mobile devices

Mobile experience is the highest priority.

---

# Primary Device Targets

The product must work smoothly on:
- low-end Android devices
- mid-range Android devices
- iPhones
- tablets

Always optimize for:
- small screens
- slow networks
- touch interactions
- limited device performance

---

# Layout Rules

Always design mobile-first.

Start with:
- single-column layouts
- stacked sections
- vertical scrolling
- touch-friendly spacing

Avoid:
- desktop-first layouts
- overcrowded interfaces
- complex multi-column mobile layouts

---

# Responsive Design Rules

Every component must support:
- mobile
- tablet
- desktop

Never assume desktop screen size.

Avoid:
- fixed widths
- horizontal overflow
- oversized content blocks

Use:
- fluid layouts
- responsive spacing
- scalable typography

---

# Touch Interaction Rules

All interactions must be touch-friendly.

Minimum touch target:
- 44px × 44px

Buttons and interactive elements must remain:
- easy to tap
- clearly visible
- properly spaced

Avoid:
- tiny buttons
- crowded interactions
- hover-dependent functionality

---

# Navigation Rules

Mobile navigation should remain:
- simple
- lightweight
- thumb-friendly

Prefer:
- bottom actions
- collapsible navigation
- clean mobile menus

Avoid:
- complex nested menus
- overcrowded navigation
- excessive sidebar dependency on mobile

---

# Typography Rules

Typography must remain highly readable on small screens.

Avoid:
- tiny font sizes
- compressed line heights
- overly decorative fonts

Preferred minimums:
- body text: 14px–16px
- touch-friendly spacing
- generous line-height

---

# Spacing Rules

Mobile layouts require breathable spacing.

Use:
- consistent spacing scale
- sufficient padding
- clear visual separation

Avoid cramped layouts.

Whitespace improves perceived premium quality.

---

# Performance Rules

Mobile performance is critical.

Always:
- lazy load media
- optimize images
- reduce JavaScript payload
- minimize rerenders

Avoid:
- heavy animations
- unnecessary client-side rendering
- large bundles

The product must remain smooth on low-end devices.

---

# Animation Rules

Animations on mobile must remain:
- subtle
- performant
- lightweight

Avoid:
- excessive parallax
- large blur effects
- animation-heavy pages

Motion should never reduce responsiveness.

---

# Forms & Inputs

Forms must remain:
- touch-friendly
- simple
- easy to complete on mobile

Inputs should:
- use proper keyboard types
- support autofill
- remain large and readable

Avoid:
- multi-column forms on mobile
- excessive input density
- small touch areas

---

# Scroll Behavior

Scrolling should feel:
- smooth
- natural
- uninterrupted

Avoid:
- scroll-jacking
- excessive sticky elements
- nested scrolling containers

Vertical flow should remain simple.

---

# Media Rules

Images and videos must:
- scale responsively
- load progressively
- avoid layout shifts

Use:
- responsive image sizing
- optimized formats
- lazy loading

---

# Dashboard Rules

Dashboard UX must remain usable on mobile.

The dashboard should:
- simplify editing
- avoid clutter
- prioritize core actions

Prefer:
- collapsible panels
- stacked layouts
- bottom action areas

Avoid enterprise dashboard complexity.

---

# Editor Experience Rules

The invitation editor must remain:
- responsive
- smooth
- easy to use on touch devices

Preview and editing flows should feel immediate.

Avoid:
- laggy updates
- tiny controls
- complex editing interfaces

---

# Accessibility Rules

Maintain:
- readable contrast
- scalable typography
- accessible touch targets

Accessibility should not be sacrificed for aesthetics.

---

# Testing Rules

All features must be tested on:
- small Android screens
- iPhone screen sizes
- tablet layouts

Use real-device testing whenever possible.

Never rely only on desktop browser resizing.

---

# Final Principles

Always prioritize:
1. mobile usability
2. touch experience
3. performance
4. readability
5. smooth interactions

The product should feel:
- lightweight
- elegant
- fast
- effortless on mobile devices
