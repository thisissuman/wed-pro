# Design Language

## Core Design Philosophy

This product should feel:
- premium
- elegant
- emotional
- cinematic
- modern
- lightweight
- smooth
- warm

The experience should feel luxurious without becoming visually heavy.

Avoid:
- cluttered UI
- flashy effects
- overly corporate SaaS design
- aggressive gradients
- excessive glassmorphism
- generic dashboard aesthetics

The product should create an emotional connection, especially on mobile devices.

---

# User Experience Philosophy

The platform is primarily used by:
- couples
- families
- wedding guests
- non-technical users

The UI should feel:
- intuitive
- effortless
- calming
- celebratory
- easy to navigate

Every interaction should reduce friction.

---

# Mobile-First Design

Mobile experience is the highest priority.

Design everything for:
- small screens first
- thumb-friendly interaction
- touch gestures
- smooth scrolling
- low-end Android devices

Desktop layouts should adapt from mobile, not the reverse.

---

# Visual Tone

Preferred visual characteristics:
- soft elegance
- spacious layouts
- refined typography
- subtle motion
- premium minimalism
- warm color palettes

Avoid:
- harsh contrast
- noisy backgrounds
- overly saturated colors
- cramped layouts
- heavy UI borders

---

# Typography

Typography is one of the most important parts of the product.

Typography should feel:
- elegant
- readable
- premium
- emotional

---

## Preferred Font Pairings

### Headings
Use elegant serif fonts:
- Playfair Display
- Cormorant Garamond
- DM Serif Display

### Body Text
Use clean sans-serif fonts:
- Inter
- Poppins
- Manrope

---

## Typography Rules

### Headings
- large
- breathable
- elegant
- high line-height

### Body Text
- highly readable
- simple
- minimal

Avoid:
- tiny font sizes
- compressed text
- decorative body fonts
- excessive font mixing

Maximum:
- 2 primary font families

---

# Spacing Philosophy

Spacing should feel:
- breathable
- premium
- uncluttered

Avoid cramped layouts.

Use generous whitespace.

Preferred spacing system:
- 4
- 8
- 12
- 16
- 24
- 32
- 48
- 64

Consistency is mandatory.

---

# Layout Principles

Layouts should:
- feel balanced
- prioritize readability
- guide emotional storytelling

Avoid:
- excessive columns
- dashboard overcrowding
- tiny clickable areas

Prefer:
- clean sections
- vertical rhythm
- card-based layouts
- smooth section transitions

---

# Color Philosophy

Colors should feel:
- luxurious
- warm
- romantic
- modern

Avoid:
- neon palettes
- aggressive gradients
- random accent colors

Preferred tones:
- ivory
- champagne
- gold
- rose
- beige
- warm neutrals
- muted earthy tones

Dark mode should feel cinematic, not cyberpunk.

---

# Color Usage Rules

Use:
- one primary accent
- one neutral background system
- subtle contrast

Avoid:
- too many accent colors
- strong red/green combinations
- visually noisy gradients

Consistency is critical.

---

# Button Design

Buttons should feel:
- soft
- premium
- tactile
- clean

Avoid:
- overly rounded cartoon buttons
- thick borders
- heavy shadows

Preferred:
- medium border radius
- subtle hover states
- clean typography
- elegant padding

---

# Card Design

Cards should:
- feel lightweight
- maintain visual separation
- avoid excessive decoration

Use:
- soft shadows
- subtle borders
- generous spacing

Avoid:
- hard outlines
- excessive blur
- overly glossy effects

---

# Form Design

Forms should feel:
- simple
- approachable
- mobile-friendly

Inputs should:
- have clear labels
- large touch targets
- clean focus states

Avoid:
- tiny form controls
- complex multi-column forms on mobile
- overwhelming interfaces

---

# Dashboard Design Philosophy

The dashboard is a creation space.

It should feel:
- calm
- focused
- lightweight
- intuitive

Avoid:
- admin-panel aesthetics
- enterprise dashboard complexity
- overcrowded sidebars

The dashboard should guide users naturally.

---

# Invitation Editor Design

The editor experience should prioritize:
- live feedback
- clarity
- simplicity
- emotional engagement

Preferred structure:
- left controls
- right live preview

Editing should feel instant and smooth.

---

# Public Invitation Design

Invitation pages should feel:
- cinematic
- emotional
- immersive
- elegant

The guest experience matters more than flashy effects.

Focus on:
- storytelling
- typography
- smooth scrolling
- visual hierarchy

Avoid:
- excessive animations
- laggy transitions
- noisy backgrounds

---

# Animation Philosophy

Animations should:
- enhance emotion
- guide interaction
- improve flow

Animation style:
- soft
- smooth
- subtle
- cinematic

Preferred:
- fade transitions
- gentle slide motion
- subtle scaling
- elegant page reveals

Avoid:
- bounce-heavy animations
- aggressive motion
- excessive parallax
- scroll-jacking

Performance is more important than animation complexity.

---

# Motion Timing

Preferred durations:
- 150ms to 500ms

Use easing that feels:
- natural
- smooth
- premium

Avoid abrupt transitions.

---

# Image Usage

Images are central to the experience.

Images should:
- feel emotional
- maintain quality
- load quickly
- preserve warmth

Avoid:
- over-sharpening
- heavy filters
- inconsistent aspect ratios

Use:
- responsive images
- lazy loading
- optimized delivery

---

# Iconography

Icons should:
- remain minimal
- support clarity
- never dominate UI

Preferred:
- thin outline icons
- clean modern icon sets

Avoid:
- oversized icons
- decorative icon overload

Use Lucide icons primarily.

---

# Responsive Design Rules

All designs must:
- work perfectly on mobile
- scale cleanly on tablets
- remain elegant on desktop

Avoid:
- fixed layouts
- overflow issues
- desktop-only thinking

---

# Loading Experience

Loading states should feel polished.

Use:
- skeleton loaders
- subtle shimmer
- smooth transitions

Avoid:
- blank white screens
- aggressive spinners
- layout shifts

---

# Empty States

Empty states should feel:
- friendly
- elegant
- helpful

Avoid generic placeholder text.

Guide users naturally.

---

# Visual Consistency

Maintain consistency across:
- spacing
- typography
- button styles
- shadows
- radii
- animations

Avoid inconsistent UI patterns.

---

# Accessibility

Maintain:
- readable contrast
- scalable typography
- accessible touch targets

Accessibility should not be sacrificed for aesthetics.

---

# Design Inspiration References

The visual direction should feel inspired by:
- luxury wedding brands
- modern editorial layouts
- cinematic storytelling
- premium mobile apps

Not:
- enterprise SaaS dashboards
- crypto websites
- flashy startup landing pages

---

# Final Design Principles

Always prioritize:
1. emotional experience
2. clarity
3. elegance
4. mobile usability
5. performance
6. smooth interaction
7. visual consistency

The product should feel:
- premium but simple
- emotional but modern
- elegant but lightweight

Every design decision should support that direction.
